
# Raw Data

This folder contains the original station-level CSV files from the Beijing Multi-Site Air Quality Dataset used in the QM640 Data Analytics Capstone project.

## Data Source

Beijing Multi-Site Air Quality Dataset  
UCI Machine Learning Repository

The dataset contains hourly air quality and meteorological observations collected from 12 monitoring stations in Beijing, China, from 1 March 2013 to 28 February 2017.

## Monitoring Stations

- Aotizhongxin
- Changping
- Dingling
- Dongsi
- Guanyuan
- Gucheng
- Huairou
- Nongzhanguan
- Shunyi
- Tiantan
- Wanliu
- Wanshouxigong

The raw files are retained in their original station-level format. Data integration, preprocessing, feature preparation, one-hour-ahead target construction, exploratory analysis, and machine learning modelling are performed in the project notebook.

## Dataset Reference

Chen, S. (2017). Beijing Multi-Site Air Quality [Data set]. UCI Machine Learning Repository. https://doi.org/10.24432/C5RK5G
